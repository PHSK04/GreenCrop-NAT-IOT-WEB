# Hydroponic Rack Control v2 — ต้นแบบแยก

แสดงโมเดลเครื่องของผู้ใช้สองมุมพร้อมกัน: ภาพรวมตรงและด้านแผงควบคุม ทั้งคู่ใช้โมเดลและสถานะการจำลองเดียวกัน พื้นหลังสีเทาอ่อนและการ์ดเซนเซอร์ตามคลิปอ้างอิง

## การใช้งาน

- รอระดับน้ำคงที่ 5 วินาที แล้วกดปุ่มเขียวล่าง (Start) บนโมเดลด้านขวา
- ปุ่มแดงล่าง: Stop ปิดปั๊มและ Alarm ทันที กระแสน้ำและคลื่นค่อย ๆ สงบ
- ปุ่มเขียวบน / ขาวบน: Auto / Manual หรือใช้สวิตช์หมุน
- ปุ่มแดงใหญ่: หยุดฉุกเฉิน เข้าสถานะ Fault
- ปุ่ม «รอบใหม่»: เริ่มการจำลองใหม่
- แตะตัวถาดในภาพรวมโดยตรงเพื่อสลับทึบ/โปร่งใส ไม่รีเซ็ตวงจร
- ปุ่ม «ขยายแผงควบคุม» ขยายมุมขวา ปุ่มบนโมเดลกดได้ทั้งมุมเต็มเครื่องและมุมขยาย

- แตะตัวพัดลมโดยตรง: ฝาครอบค่อย ๆ โปร่งใส เห็นใบพัดหมุน เส้นลมลงถาด และคลื่นน้ำเล็ก ๆ จากลม แตะซ้ำเพื่อปิด
- แตะตัวโคมไฟโดยตรง: ฝาครอบโปร่งใส เห็นแหล่งกำเนิดแสงและแสงอุ่นลงถาด แตะซ้ำเพื่อปิด
- สายดำจัดเป็นแนวตรงขนาน แยกช่องเดินสาย พื้นหลังโรงปลูกพร้อมกระจกและต้นไม้
- สองมุมมีพื้นที่เท่ากัน ปุ่มนูนกดยุบและสวิตช์หมุนตามสถานะ จำกัดความละเอียดและแคชเงาเพื่อให้กดได้ลื่นขึ้น

## ภาพน้ำและเครื่อง

- สายฟ้าสองเส้น ใช้แนว Bezier จริงจากไฟล์ Blender สร้างคอลัมน์น้ำสีที่เคลื่อนในสาย ไม่มีลูกกลมลอย
- เมื่อหยุด คอลัมน์น้ำในสายอยู่นิ่ง ผิวน้ำเรียบ ไม่มีคลื่น ฟอง หรือการสั่นวน
- เมื่อ Start กระแสน้ำค่อย ๆ เพิ่ม ผิวน้ำเกิดคลื่นและฟองเฉพาะตอนน้ำไหล ระดับต้นทางลดและปลายทางเพิ่ม
- Stop ทำให้น้ำและคลื่นชะลอจนหยุด เครื่องและสายที่อยู่ในกลุ่มเดียวกันกลับมานิ่ง
- ไฟขาว Manual, เขียว Auto, เหลืองปั๊ม, แดง Fault, ไฟ Alarm ตามสถานะ จังหวะกะพริบไม่ได้อนุมานจากคลิปที่มองไม่ชัด
- ปลายทางเต็มหยุดปั๊มและแสดง Alarm 5 วินาที ส่วน Emergency และ timeout 600 วินาทีจำลองเข้าสู่ Fault

โมเดลต้นฉบับ `reference/hydroponic-rack-control-v2.blend` เก็บไว้โดยไม่แก้ไข ส่งออกสำเนาด้วย `models/export_model.py` เป็น `models/hydroponic-rack-control-v2.glb` และเส้นทางสาย `models/hose-paths.json`

นี่เป็นการจำลองเชิงภาพ ไม่ใช่การคำนวณของไหลหรือการสั่งอุปกรณ์จริง ค่า Humidity 62%, pH 5.8 และ EC 1.4 mS/cm เป็นข้อมูลตัวอย่าง ไม่มีการส่งข้อมูลไปเซิร์ฟเวอร์หรือ deploy

## เปิดในเครื่อง

จากโฟลเดอร์หลัก:

```sh
npx vite --config development/hydroponic-rack-3d/prototype/vite.config.mjs
```

เปิด http://127.0.0.1:3010 รับการเชื่อมต่อเฉพาะในเครื่อง

## ตรวจสอบ

```sh
node --test development/hydroponic-rack-3d/prototype/*.test.mjs
npx vite build --config development/hydroponic-rack-3d/prototype/vite.config.mjs
```

ไฟล์ build อยู่ที่ `preview-dist/` ซึ่งถูกละเว้นจาก Git

## ฉากห้องตามภาพอ้างอิงล่าสุด

ห้องสามมิติผนังแผงสีขาวนวล ไฟมิ้นต์ไล่ความสว่างเบา ๆ ไฟฟ้าระดับพื้น โคมเพดานโทนอุ่น กระจกพร้อมใบไม้ไหว และจอกราฟขยับ ทั้งสองมุมใช้ฉากเดียวกัน รองรับ reduced motion การเคลื่อนไหวในห้องแยกจากปั๊ม จึงยังเคลื่อนไหวอย่างสงบได้เมื่อเครื่องหยุด

## React / Gatsby

หน้าต้นแบบใช้ `prototype/HydroponicRoom.jsx` เป็นคอมโพเนนต์ React และ `prototype/rack-scene.js` เป็น Three.js renderer ที่สร้าง/ทำลายใน useEffect ใช้กล้องและพื้นจริงเพียงชุดเดียวสำหรับเครื่องทั้งสองตำแหน่ง ไม่มีการ์ดค่าเซนเซอร์ลอย สายน้ำจัดเป็นช่วงตรงขนานพร้อมข้อโค้งสั้นตรงจุดเชื่อม

สำหรับนำไปใช้ใน Gatsby ให้นำโฟลเดอร์ prototype และ models ไปด้วยกัน รักษาโครงสร้างพาธ แล้ว import คอมโพเนนต์:

```jsx
import HydroponicRoom from '../components/hydroponic/prototype/HydroponicRoom';
export default function MachinePage() { return <HydroponicRoom />; }
```

ต้องมี react, react-dom และ three คอมโพเนนต์ lazy-load WebGL เฉพาะเบราว์เซอร์เพื่อรองรับ SSR และคืนทรัพยากรเมื่อ unmount สไตล์จำกัดขอบเขตใน `.hydroponic-room` ไม่เปลี่ยน body ของหน้า Gatsby ยังไม่ได้ทดสอบ build กับโครงการ Gatsby จริง

ปุ่ม «สาธิตผู้ดูแล» เรียกตัวละครเดินไปกด Start หนึ่งครั้งแล้วเดินกลับ ไม่เล่นวน การกด Stop หรือ Fault ยกเลิกการเดินและคำสั่ง Start ที่ยังไม่เกิดขึ้น เพิ่มแสงวิ่งช้าตามแนวขอบห้องและเส้นลมเบา ๆ โดยเคารพ reduced motion

ปรับตามคำยืนยันล่าสุด: ใช้เฉพาะถาดเดิมในไฟล์ v2 ไม่มีถาดชั้นกลางหรือคานรองที่เพิ่มขึ้น ป้ายถาดเพาะเลี้ยงอยู่บนถาดเดิมด้านบน และถาดเก็บเกี่ยวอยู่ถาดเดิมล่างสุด

## โทนการ์ตูน 3D และแอนิเมชันห้อง

ปรับโทนเครื่องเป็นเขียวเทา พาสเทล และแสงอุ่น วัสดุถาดยังคงสัดส่วนต้นฉบับ เพิ่มแสงวิ่งตามผนังและขอบพื้น พัดลมระบายอากาศพร้อมเส้นลม และกราฟบนผนังที่เคลื่อนไหว ปุ่ม «พักฉาก» หยุดเฉพาะแอนิเมชันบรรยากาศ ไม่เปลี่ยนวงจรเครื่อง ปุ่ม «เล่นฉาก» เปิดต่อ รองรับ reduced motion และจำกัดความละเอียดเรนเดอร์เพื่อให้ปุ่มตอบสนองดีขึ้น

อัปเดตแนวสายน้ำ: ยึดศูนย์กลางข้อต่อที่อ่านจาก Blender (X -0.510/-0.488, ระยะลึก 0.150, ระดับ 1.020/0.700/0.390/0.290) ท่อบนและล่างต่อกันที่ระดับ 0.700 แถบฟ้าอ่อนสลับฟ้าเคลื่อนลงทิศเดียวกัน มีแขนงสั้นเข้าถาดและสายน้ำตกที่ต่อกับปลายแขนง

เพิ่มความสมจริงด้วยแสงสะท้อนสภาพแวดล้อมจาก RoomEnvironment (สร้างในเครื่อง ไม่โหลด HDR ภายนอก) แยกค่าความเป็นโลหะและความหยาบของสแตนเลส โครงพ่นสี HDPE ยาง และขอบนิกเกิล พร้อมเงา PCF ที่นุ่มขึ้นและพื้นสะท้อนแสงอย่างพอดี ยังคงสีแสดงทิศทางน้ำไว้

เทียบคลิปอ้างอิงรอบล่าสุด: ปรับพัดลมห้องเป็นใบพัดโค้งสีอ่อน 5 ใบในกรอบเข้ม เพิ่มพืชใบโค้งและเส้นใบในกระถางขอบห้อง ใบพืชไหวเบา ๆ ไม่เพิ่มถาดให้เครื่อง และเว้นระยะระหว่างจอผนังกับพัดลม พัดลมในเครื่องคงตำแหน่งเดิมและแสดงใบพัดขณะทำงานผ่านฝาครอบโปร่งแสง
